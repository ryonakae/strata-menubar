# Idle Unload and Engine Switches Implementation Plan

dig log: [docs/dig/2026-10-15-idle-unload-and-engine-switches.md](../dig/2026-10-15-idle-unload-and-engine-switches.md)（決定事項・対象外・撤回済みの正本。既定値の表とサーバー／エンジン側の挙動もここにある）

## Requirements

Strata の 5 項目（Idle unload、`fit_max_tokens`、`--spec N`、`STRATA_METAL_PROMPT_CHUNK`、`STRATA_METAL_KEEP_FREE_GB`）を設定できるようにし、あわせて Expert cache を「Auto / 固定」にする。メニューは設定値の表示だけにし、変更は設定画面で行う。前回までの制約はそのまま守る：Strata checkout・モデル・クライアント設定を書き換えない、run config は管理キーだけ変える、保存は次回起動に反映、再起動は明示操作のみ、自動再起動なし、127.0.0.1 のみ。

- **Expert cache**: 「Auto」と「固定 N GB」の二択。Auto では run config に `STRATA_METAL_ARENA_GB` を書かず、エンジンが arena を決める。保存値がない新規ユーザーの既定は Auto。`expertCacheGB` が保存済みの既存ユーザーは固定のまま（移行処理なし）。固定時の警告（2 GB 未満、物理メモリの半分超）は今のまま。README の「5 GB で約 13 GB」は固定モードの説明として残す。
- **Keep free（`STRATA_METAL_KEEP_FREE_GB`）**: Auto のときだけ有効。「Engine default」+ 1 GB 刻み（1 GB〜物理メモリの GiB）。Engine default は run config に書かない。表示は「7 GB or 15% of RAM, whichever is more (N GB on this Mac)」と計算値を添え、Strata の docs（MAC.md / arena_budget.h）による旨を書く。7 GB 未満は警告（34 分の soak で 5 GB 残しでは arena 充填中に 93 MB が swap out した実測が根拠）。
- **Idle unload**: Never / 5 / 10 / 15 / 30 / 60 / 120 min。Never は run config に書かない。一覧にない保存値は現在値の項目として並べる（Context と同じ）。idle unload 付きで起動したサーバーが `/health` で `loaded: false` を返したら、`ServerState.running` のまま「Running on port N: model, context C (model unloaded after idle; loads on the next request)」のように中立に表示し、health 異常扱い（警告アイコン・「health check:」接尾辞）にしない。idle unload なしで起動したサーバーは従来どおり「— health check: model not loaded」。再ロード中も同じ文言になる（サーバーは区別する情報を返さない）。Open Chat / Stop / Quit / 未反映判定は変更なし。
- **`--spec N`**: 「As set up (N)」+ 2〜8。As set up は base config の `args` を触らない（N は base から読んで表示）。base に `--mtp` がなければ「This model's config has no MTP draft layer (--mtp); --spec has no effect」の注記を出すが、選択肢は無効化しない。5 以上に警告（M5 Max の計測で 5〜6 は遅い）。
- **Prompt chunk（`STRATA_METAL_PROMPT_CHUNK`）**: 「Auto (N on this Mac)」+ 1024 / 2048 / 4096 / 8192。Auto は run config に書かない。N は物理メモリと base の `env.STRATA_METAL_STREAM` から計算（常駐 2048、ストリーミングは RAM 96 GiB 以上で 4096、未満で 1024）。`STRATA_METAL_STREAM` が base にないときは「Auto (the engine decides by model size)」と数値なし。ストリーミング config でこの Mac の既定より大きい値に警告（4096 ではプロンプト処理中に 4.3 GB のバッファが arena から取られる実測を根拠に）。
- **`fit_max_tokens`**: チェックボックス、既定オフ、true のときだけ run config に書く。注記に「プロンプト自体が context を超える場合は救えない（max_tokens を切り詰めるだけ）」を添える。
- **`STRATA_METAL_STREAM` の補完をやめる**: base の `env` に無ければ run config にも書かず、エンジンがモデルサイズで決める。
- **メニュー**: Model ▸ / Expert cache ▸ / Context ▸ のサブメニュー（選択で即保存）を廃止。保存値（次回起動に使う値）を 1 項目 1 行で表示する。Model、Expert cache（Auto / N GB）、Context、Port、Idle unload は常に、Keep free / Spec / Prompt chunk / Fit max tokens は既定（Engine default / As set up / Auto / off）でないときだけ。稼働中サーバーの起動時の値と違う行には「(running: X)」を添える。行を押すと設定画面が開く。状態行、「Saved settings differ from the running server」、Start / Stop / Stop and Apply、Open Chat、ログ、Settings…、Quit は維持。
- **設定画面**: 下書き + Apply / Revert の方式は変更なし。「Memory and context」に Expert cache（Auto トグル + スライダー）、Keep free、Context、Prompt chunk。新設「Server」に Port、Idle unload、Fit max tokens。新設「Engine」に Spec（`--mtp` なしの注記つき）。警告・注記は `StrataSettings.validate` に集約。「Started with」の文字列はメニューと同じ規則（五つは常に、チューニング項目は既定でないときだけ）。新項目はすべて `StrataSettings` のフィールドにし、等値比較による未反映判定に自動で含める。
- **ドキュメント**: README の Use / Settings / 管理キー一覧 / Limitations と、AGENTS.md の invariant「the menu saves at once, the settings window via Apply」を改める。管理キーは `--max-context`、`--spec`（変更時のみ）、`STRATA_METAL_ARENA_GB`（固定時のみ）、`STRATA_METAL_KEEP_FREE_GB`（Auto で指定時のみ）、`STRATA_METAL_PROMPT_CHUNK`（指定時のみ）、`idle_unload_s`（Never 以外）、`fit_max_tokens`（true のみ）、`log`、`port`。
- **対象外**: 5 項目以外のスイッチ、`--lazy`、`--host` / `--api-key`、setup 時に決まる `--vision` / `--mtp` / `--draft-vocab`、メニューからの Unload Now / Load Now、`.window` スタイルのポップアップ、自動再起動。

## Implementation Decisions

- **設定モデル**（`StrataSettings`）: 既存の `expertCacheGB: Double` は固定時の値として残し（既定 5）、`autoExpertCache: Bool`（既定 true）を足す。新規フィールドは `keepFreeGB: Int?`（nil = Engine default）、`idleUnloadMinutes: Int`（0 = Never）、`specWindow: Int?`（nil = As set up）、`promptChunk: Int?`（nil = Auto）、`fitMaxTokens: Bool`。段は `ContextSteps` と同じ形で `IdleUnloadSteps.minutes = [0, 5, 10, 15, 30, 60, 120]`、`PromptChunkSteps.values = [1024, 2048, 4096, 8192]`、`SpecWindow.range = 2...8` を一か所に置く。
- **UserDefaults**（`SettingsStore`）: 新キー `autoExpertCache` / `keepFreeGB` / `idleUnloadMinutes` / `specWindow` / `promptChunk` / `fitMaxTokens`。`autoExpertCache` が無いときは `expertCacheGB` が保存されていれば false（既存ユーザーは固定のまま）、無ければ true。nil の Optional は `removeObject` で表す。
- **エンジン既定の計算**（新設 `EngineDefaults`、`StrataMenubar/Settings/`）: `MemoryBudget` に `physicalMemoryBytes` を持たせ、Keep free は `max(7, 0.15 × bytes / 1e9)` を 10 進 GB で小数 1 桁（32 GiB → 7 GB、128 GB → 20.6 GB。エンジンは `kGB = 1e9` と bytes で計算する）、Prompt chunk は streaming が true なら bytes ≥ 96 GiB（`96 << 30`）で 4096、未満で 1024、false なら 2048、不明（キーなし）なら nil。計算式の出典（MAC.md、arena_budget.h、window.cpp）はコメントに書く。
- **base config の事実**（`StrataInstallation.baseFacts(for tag:) -> BaseConfigFacts?`）: `args` の `--spec` の値、`--mtp` の有無、`env.STRATA_METAL_STREAM`（"1" → true、"0" → false、無し → nil）を読む。config が読めなければ nil。設定画面の「As set up (N)」「Auto (N on this Mac)」表示、メニューの表示、検証に使う。
- **検証**（`StrataSettings.validate(memory:base:)`、`base: BaseConfigFacts? = nil`）: 固定 cache の既存エラー・警告は `!autoExpertCache` のときだけ。Keep free は Auto で指定時のみ、1〜物理メモリ GiB の外はエラー、7 未満は警告。Idle unload は負ならエラー。Spec は 2〜8 の外はエラー、5 以上は警告、`base.hasMTP == false` で指定時は「has no effect」の警告。Prompt chunk は 64 の倍数で 64〜8192 の外はエラー、`base.streaming == true` でこの Mac の既定より大きければ警告。base が nil なら base 依存の警告は出さない。`hasErrors` の意味は変えない。
- **run config**（`RunConfig.make`）: 管理キーはアプリが所有し、設定が「未指定」なら run config から**取り除く**（base にそのキーがあっても）。run.json を起動設定の正本にするため。`--spec` だけは「As set up」で base の値をそのまま残す（setup が必ず書くキーなので）。具体的には `args`: `--max-context` は今のまま、`--spec` は `specWindow` 指定時に `--max-context` と同じ置換・追加。`env`: `STRATA_METAL_ARENA_GB` は固定時のみ、`STRATA_METAL_KEEP_FREE_GB` は Auto かつ指定時のみ、`STRATA_METAL_PROMPT_CHUNK` は指定時のみ、それ以外は削除。`STRATA_METAL_STREAM` には触れない。base に `env` が無く書くキーも無ければ `env` を足さない。トップレベル: `idle_unload_s` は `minutes × 60` の整数（Never なら削除）、`fit_max_tokens` は Swift の `Bool` `true`（JSON の `true` になること。false なら削除）、`log`、`port` は今のまま。
- **稼働中の表示**: `RunningInfo` に `var isIdleUnloaded: Bool { health == .notLoaded && settings.idleUnloadMinutes > 0 }` を足す。`ServerState+Display` の `statusText` はこのとき「(model unloaded after idle; loads on the next request)」を付けて `health.suffix` を付けず、`symbolName` は `moon.circle`（警告アイコンにしない）。`ServerManager` の monitor / readiness は変更なし（起動時は従来どおり `loaded: true` を待つ。idle unload は起動後にしか起きない）。アプリの 10 秒ごとの `/health` はサーバーのアイドル判定（`last_request_at`）を更新しない（server.py で更新するのは生成・`/load`・slot 保存・画像リクエストだけ）ので、監視がアンロードを妨げることはない。
- **メニュー**（`MenuContent`）: `binding(_:)` と 3 つの `Menu` を削除。`Section("Settings for the next start")` に行を `Button` で並べ、押すと `openSettings()`（既存の Settings… と同じ）。Model の表示名は今までどおり `installedModels()` の `modelName`。「(running: X)」は `state.runningInfo?.settings` と保存値を項目ごとに比べて付ける。
- **設定画面**（`SettingsView`）: Auto トグルで Expert cache スライダーを無効化し Keep free のポップアップを有効化（固定時は逆）。Keep free / Idle unload / Spec / Prompt chunk は `Picker` のポップアップ（先頭が Engine default / Never / As set up (N) / Auto (N on this Mac)）。`baseFacts` は `checkInstallation()` と同じタイミング（ディレクトリ・モデル変更時）で読み直す。`describe(_ settings:)` を「Started with」の規則に合わせる。
- **フェイクとテスト**: `TestInstallation` の base config は今のまま（`--spec 2`、`--mtp` なし、`STRATA_METAL_STREAM: "1"`）で、`--mtp` あり・`env` なしの変種はテスト内で base 文字列を書き換えて作る（`RunConfigTests` の既存パターン）。
